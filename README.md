# Cho Eunseo — 3D Portfolio

정적 홈페이지입니다. 서버도, 빌드도, 데이터베이스도 필요 없습니다.
`index.html` 을 더블클릭하면 바로 열립니다.

## 폴더 구성

| 폴더 / 파일 | 설명 |
|---|---|
| `index.html` | 화면과 동작 전부. **거의 고칠 일 없습니다.** |
| `data.js` | **내용은 여기만 고칩니다.** 이름, 소개, 작업 목록 |
| `images/` | 원본 이미지 (보관용). 홈페이지는 이 폴더를 쓰지 않습니다 |
| `thumbs/` | 카드·썸네일용 축소본 (긴 변 900px) |
| `web/` | 크게 보기용 축소본 (긴 변 1700px) |
| `favicon.png` | 브라우저 탭 아이콘 |
| `.gitignore` | `images/` 를 GitHub 에 안 올리도록 설정 |

원본 470MB → 웹용 23MB. 그래서 페이지가 빠릅니다.

## 작업을 추가하려면

1. `images/Personal/` 안에 `YYYYMM_제목` 폴더를 만들고 이미지를 넣습니다.
2. `thumbs/Personal/` 과 `web/Personal/` 에 같은 이름의 폴더를 만들고,
   축소한 `.jpg` 를 같은 파일명으로 넣습니다.
   (귀찮으면 저에게 "새 폴더 넣었어, 축소본 만들어줘" 라고 말씀하세요)
3. `data.js` 의 `personal` → `groups` 맨 위에 한 덩어리를 복사해 붙이고
   `folder` / `title` / `date` / `cover` / `files` 를 고칩니다.

`files` 에 적는 이름은 **원본 파일명 그대로**입니다.
확장자가 `.png` 여도 그대로 적으면 됩니다. 축소본 경로는 자동으로 찾아갑니다.

## GitHub Pages 로 올리기

1. GitHub 에서 저장소를 하나 만듭니다. 이름은 `Cho_Artwork_Homepage` 로 하면 됩니다.
2. 이 폴더의 파일을 전부 올립니다. (`.gitignore` 덕분에 `images/` 는 안 올라갑니다)
3. 저장소 → **Settings → Pages** → Source 를 `Deploy from a branch`,
   Branch 를 `main` / `/ (root)` 로 두고 Save.
4. 1~2분 뒤 주소가 나옵니다:
   `https://<내아이디>.github.io/Cho_Artwork_Homepage/`

아이디가 주소가 되는 방식은 이것 하나뿐입니다.
`<내아이디>.github.io` 라는 이름으로 저장소를 만들면 뒤에 저장소 이름이 안 붙고
`https://<내아이디>.github.io/` 가 됩니다. 둘 중 편한 쪽을 고르면 됩니다.

## 동작 정리

- 첫 화면 → About → Works 순서
- 카드 위에 마우스를 올리면 **날짜가 제목 위에** 나타납니다
- 카드를 누르면 크게 보기(라이트박스)가 열립니다
  - `←` `→` 또는 **마우스 휠**로 이동 (같은 카테고리 안에서만 순서대로)
  - 오른쪽에 같은 작업의 이미지 목록이 함께 보입니다
  - `ESC` 또는 바깥을 누르면 닫힙니다
- 스크롤을 내리면 카드가 이어서 불러와집니다
- `Email ✉` 를 누르면 이메일 주소가 복사되고 화면 가운데에 안내가 뜹니다
- 조회수는 **보는 사람의 브라우저에만** 저장됩니다 (서버 없음).
  같은 방문에서 같은 작업은 1번만 셉니다. 10회 이상일 때만 숫자가 보입니다.
- 최근 작업에는 `NEW` 표시가 자동으로 붙습니다 (`date` 기준)
